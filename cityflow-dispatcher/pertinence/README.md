# pertinence/ (vendored, unchanged)

Copies of the original PERTINENCE search (`search/`, from archive/dispatcher) and evaluation
(`analysis/`, from archive/dispatcher_analysis) code. The files are byte-for-byte the originals, so the
methodology is the one used for the COCO runs. Only the config and entry points live outside, in
`pertinence_config.py` and `08_pertinence_search.py` / `09_pertinence_analysis.py`.
